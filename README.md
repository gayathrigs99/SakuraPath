# SakuraPath

SakuraPath is an AI-powered Japanese workplace conversation practice application. It helps learners build confidence speaking Japanese in realistic workplace situations.

## What the application does

- Presents workplace scenarios for learners to practice, such as reporting a problem or asking for help.
- Lets learners answer interview-style questions by recording their voice.
- Transcribes spoken answers and uses AI to continue the conversation with relevant questions and feedback.
- Generates a PDF report summarizing a completed practice interview.
